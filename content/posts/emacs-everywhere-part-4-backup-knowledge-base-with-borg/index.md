## Summary

The Emacs hype is real, and Doom is likely the best Emacs distribution out there currently! In this series, I share my Emacs workflow, including all the bits that are not directly about Emacs.

Learn how to incrementally backup your personal knowledge base using Borg Backup. In this video, I show you how to automate this process using a couple of bash scripts, triggered by a systemd service and timer, that you can install on your Linux machine as a thin wrapper to Borg Backup.
